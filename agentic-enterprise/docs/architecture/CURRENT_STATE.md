| الوكلاء | 5 وكلاء في 3 مجالات، لكل منهم prompt وأدوات وحواجز وذاكرة وoutcomeGuard و5 evals | سياسات مرجعية حتمية مختبرة. سلوك النموذج الفعلي غير مقيس |

| الاختبار | 61 unit، و34 eval منها 4 شاملة، و41 طفرة | قوي للمنطق. **لا يغطي التزامن بين العمليات، ولا الانهيار، ولا الهوية** |

### 1.1 ما ليس موجودًا رغم أن السياق قد يوحي به

- **تكاملات n8n:** لا يوجد أي تكامل مع n8n. المستودع المضيف هو مستودع وثائق n8n فقط، وخادم n8n MCP في هذه الجلسة فشل في الاتصال.
- **تعدد المستأجرين (multi-tenancy):** غير موجود. كل البيانات في نطاق واحد.
- **مزوّدو النماذج:** Claude Agent SDK فقط، ولا طبقة تجريد لمزوّدين آخرين.
- **CI/CD:** لا يوجد pipeline للمشروع. الـ workflows الموجودة في `.github/` تخص وثائق n8n.

## 3. ضوابط الأمن القائمة (مثبتة باختبارات)

1. كل إجراء لا رجعة فيه يمر بموافقة بشرية، في طبقتين: المنفّذ والـ connector. مختبر بالطفرات.
2. التفويض يُستهلك مرة واحدة، ومربوط بنوع الإجراء والمبلغ، ويُبطل بتعديل الحمولة.
3. SoD: لا يوافق المنشئ، ولا يوافق الشخص مرتين، والدور يجب أن يكون مسموحًا.
4. المحتوى الخارجي يُغلَّف ويُفحص، والأدوات ذات الأثر تأخذ معرّفات فقط والقيم من النظام المرجعي.
5. outcomeGuard يطابق ادعاءات الوكيل مع النظام المرجعي.
6. حجب PII في الذاكرة، والنسيان عند انتهاء المهمة، والمحو بالموضوع.
7. لا أسرار في الكود (`.env.example` فقط).

## 5. الديون التقنية

1. **الـ CLI أحادي العملية،** وحالة الـ mocks في ملف JSON يُكتب بالكامل في كل أمر. أمران متزامنان قد يفقدان تحديثات (آخر كاتب يفوز).
2. `transaction()` يبدأ بـ `BEGIN IMMEDIATE` ولا يدعم التداخل، فلا يمكن تغليف `audit.append` المستدعى من داخل معاملة أخرى.
3. بعض قيم السياسة متكررة، مثل حد 50 ألف دولار في السياسة وفي حد التقسيم بالمشتريات.
4. `amount_usd = -1` كتمثيل لعملة غير معروفة (sentinel).
5. لا يوجد linter أو formatter. الاعتماد على `tsc --strict` وحده.

## 7. فجوات الاختبار والموثوقية

- لا اختبارات متعددة العمليات، فالـ 61 اختبارًا تعمل كلها في عملية واحدة وقاعدة في الذاكرة.
- لا اختبار انهيار أو استعادة، ولا اختبار لمهلة التشغيل.
- لا اختبار لهوية الموافق.
- الوضع الحي غير مقيس، فلا يوجد خط أساس لسلوك النموذج الفعلي: الدقة، والتكلفة، ومعدل التصعيد.
- لا اختبارات حمل.

## 10. خارطة التنفيذ المرتبة

التفصيل والحالة الحية في [`../roadmap/IMPLEMENTATION_ROADMAP.md`](../roadmap/IMPLEMENTATION_ROADMAP.md).

1. **P0-1:** إصلاح فتح القاعدة (R2)، ومعاملات متداخلة آمنة، وتسلسل كتابة audit (R1).
2. **P0-2:** مطالبة ذرية بالمهام برمز إيجار، ورفض استدعاءات التشغيل الزومبي، واستعادة المهام المنتهي إيجارها (R3، R4، R8).
3. **P0-3:** نقاط تثبيت audit موقعة خارج القاعدة، تكشف الحذف وإعادة الكتابة. وفحص السلامة قبل كل إجراء لا رجعة فيه (R5، R6).
4. **P0-4:** توقيع قرارات الموافقة بمفاتيح Ed25519 لكل موافق، مربوطة بالإجراء وhash الحمولة (R7).
5. **P1:** منع تكرار طلبات الموافقة، والسحب، وسبب الرفض الإلزامي، ومهلة التشغيل، وbackoff.
6. **P1:** سجل الوكلاء بالإصدارات ودورة الحياة ومستويات الاستقلالية، وإيقاف وكيل بعينه.
7. **P1:** CI لهذا المشروع، وفحص الأسرار، وSBOM، واختبار النسخ والاستعادة.
8. **P2 فما بعد:** تعدد المستأجرين، وتجريد المزوّدين، وAPI، والتكاملات، والإقامة الإقليمية.
