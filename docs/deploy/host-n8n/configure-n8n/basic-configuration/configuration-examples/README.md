# Configuration examples <a href="#configuration-examples" id="configuration-examples"></a>

This section contains examples for how to configure n8n to solve particular use cases.

## In this section

* [Isolate n8n](isolate-n8n.md): prevent your n8n instance from connecting with n8n's servers.
* [Configure the Base URL](configure-the-base-url.md): define the front end's access path to the back end's REST API.
* [Configure custom SSL certificate authorities](configure-custom-ssl-certificate-authorities.md): work with self-signed certificates when connecting to services.
* [Set a custom encryption key](set-a-custom-encryption-key.md): set a custom encryption key to securely encrypt credentials.
* [Configure workflow timeouts](configure-workflow-timeouts.md): set execution timeouts to determine how long workflows can run.
* [Specify custom nodes location](specify-custom-nodes-location.md): add folders and specify paths for your custom nodes.
* [Enable modules in Code node](enable-modules-in-code-node.md): allow the use of built-in and external modules in the Code node.
* [Set the timezone](set-the-timezone.md): change the default timezone for your self-hosted instance.
* [Specify user folder path](specify-user-folder-path.md): specify the location of the folder that stores user-specific data.
* [Configure webhook URLs with reverse proxy](configure-webhook-urls-with-reverse-proxy.md): customize webhook URLs for compatibility with reverse proxy setups.
* [Enable Prometheus metrics](enable-prometheus-metrics.md): enable the Prometheus metrics endpoint.
* [Pre-configure Microsoft OAuth credentials](pre-configure-microsoft-oauth-credentials.md): let users connect without their own app registration.
* [Configure a custom workflow templates library](configure-a-custom-workflow-templates-library.md): set up a custom workflow template library.
