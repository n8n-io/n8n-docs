# Environment variables overview <a href="#environment-variables-overview" id="environment-variables-overview"></a>

Environment variables are settings you configure in your hosting environment before starting n8n. They control how your self-hosted n8n instance behaves: for example, which database to use, authentication settings, performance limits, and feature toggles.

You set these variables in your deployment environment (Docker, Kubernetes, systemd, etc.) before running n8n. The tables below list every available environment variable, organized by feature area. Each entry shows the variable name, what it does, its data type, and the default value if you don't set it.

{% hint style="info" %}
**File-based configuration**

You can provide a [configuration file](../../basic-configuration.md) for n8n. You can also append `_FILE` to certain variables to provide their configuration in a separate file.
{% endhint %}
