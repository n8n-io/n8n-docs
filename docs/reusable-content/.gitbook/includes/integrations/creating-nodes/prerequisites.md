---
title: prerequisites
---
* [git](https://git-scm.com/downloads)
* Node.js and npm. Minimum version Node 18.17.0. Refer to [nvm's installation instructions](https://github.com/nvm-sh/nvm) to install both using nvm (Node Version Manager) for Linux, Mac, and WSL. For Windows users, refer to Microsoft's guide to [Install NodeJS on Windows](https://docs.microsoft.com/en-us/windows/dev-environment/javascript/nodejs-on-windows).
