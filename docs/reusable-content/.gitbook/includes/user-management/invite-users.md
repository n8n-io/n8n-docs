---
title: invite-users
---

1. Sign in to your n8n instance with an account that has the **Owner** or **Admin** instance role, or a custom instance role with the **Members** > **Manage** permission. On n8n Cloud, if you're in the n8n Cloud console, select **Open instance** on the **Overview** page.
2. Select **Instance settings** at the bottom of the left menu.
3. Select **Users** to go to the **Users** page.
4. Select **Invite**.
5. Enter the new user's email address.
6. Select **Invite user**. n8n sends an email with a link for the new user to join.
